当前最热门的一站式 AI 应用开发平台，支持工作流编排、RAG、Agent 等多种开发模式，零基础也能快速上线一个 AI 应用。Stars 突破 14 万，是 AI 应用开发入门的首选框架。

🔍 是什么

Dify 是一个开源的 AI 应用开发平台，核心理念是让 AI 应用开发变得像搭积木一样简单。它将常见的 AI 开发模式封装成可复用的模块，开发者无需从零编写复杂的 LLM 调度逻辑，通过可视化界面或 YAML 配置即可完成 AI 应用的构建。


它支持三大核心能力：

  • 工作流编排：用可视化的 DAG 方式串联多个 LLM 步骤、工具和条件分支
  • RAG 引擎：内置完整的检索增强生成流程，支持 PDF、网页、数据库等多种数据源
  • Agent 模式：基于 ReAct / Function Call 的自主代理，支持多轮对话和工具调用

📈 为什么火

  • 门槛极低：有手就会用，无需深入了解 LLM 底层原理，就能做出生产级 AI 应用
  • 功能完备：内置日志、监控、多模型切换、API 发布等企业级功能，上线后直接可用
  • 部署简单：支持 Docker 一键部署，也有云端 SaaS 版本
  • 社区活跃：14 万 Stars，贡献者众多，插件生态丰富
  • 中文友好：文档完善，有活跃的中文社区，对国内开发者非常友好
